# Инструкции для Антона

## Как создать @username в Telegram

1. Открой **Настройки**.
2. Нажми **Имя пользователя**.
3. Введи имя латиницей, от 5 символов, например `anton_ignatov`.
4. Дождись надписи **«Имя доступно»**.
5. Нажми **Готово**.

## Как подключить облачный пароль в Telegram

1. Открой **Настройки** → **Конфиденциальность** → **Облачный пароль**.
2. Нажми **Установить пароль**.
3. Введи пароль два раза.
4. Добавь подсказку.
5. Введи свою почту.
6. Введи код из письма.
7. Нажми **Готово**.
